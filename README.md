# Aurora Hotel Website

## Project Overview

Aurora Hotel is a responsive multi-page hotel website created as a Midterm Project.

The main purpose of the project is to create a simple and user-friendly hotel website where visitors can learn about the hotel, view available rooms and services, and contact the hotel.

## Pages

The website contains five main pages:

- **Home** – introduction to Aurora Hotel and featured rooms.
- **Rooms** – information about different room types, facilities and prices.
- **Services** – information about restaurant, spa, swimming pool, fitness center, room service and Wi-Fi.
- **About Us** – information about the hotel, its values and main advantages.
- **Contact** – hotel contact information and a form for guests.

## Features

The project includes:

- Responsive navigation bar
- Images and hotel information
- Room price table
- Contact form
- CSS Flexbox
- CSS Grid
- CSS positioning
- Bootstrap Grid System
- Bootstrap utility classes
- Responsive design
- Media queries for tablet and mobile screens
- Semantic HTML5 elements

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## Responsive Design

The website is designed for desktop, tablet and mobile devices.

Media queries are used at 768px and 576px breakpoints. Bootstrap responsive grid classes are also used to change the layout depending on the screen size.

## Project Structure

- `index.html` – Home page
- `rooms.html` – Rooms page
- `services.html` – Services page
- `about.html` – About Us page
- `contact.html` – Contact page
- `style.css` – Main website styles
- `rooms.css` – Rooms page styles
- `services.css` – Services page styles
- `about.css` – About Us page styles
- `contact.css` – Contact page styles
- `images/` – Website images
